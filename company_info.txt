=== اسم الشركة ===
منظومة إسناد (Esnad System)

=== نبذة عن الشركة ===
منظومة متكاملة لإدارة تقنين أوضاع الأراضي، الاعتمادات، والطلبات الإدارية. نظام تشغيل إداري رقمي يحول العمل الورقي إلى سير عمل موحد، قابل للتتبع، وفعال بشكل آمن. جاهز للتسليم الحكومي.

=== الخدمات / المنتجات الرئيسية ===
- إدارة الطلبات: مسار عمل من 9 مراحل (من التقديم حتى الإغلاق أو الرفض) مع رقم تتبع فريد لكل طلب.
- إدارة المستندات: رفع، تحقق، توثيق، صور أراضي، وثائق مالية وإدارية.
- حوكمة الأدوار والصلاحيات: 32 دور وظيفي، 59 صلاحية، و281 رابط. مع محرك SoD (فصل المهام) لمنع تضارب المصالح.
- كشف تعارضات الأراضي: كشف ذكي للاندماجات وتداخل الطلبات وربط الطلب بالأرض والوثائق ميدانياً.
- العقود والمدفوعات: إنشاء عقود قانونية، ربطها بالطلب، وتسجيل المدفوعات والإيصالات.
- بوابات مخصصة: بوابة المواطن (31 صفحة)، بوابة الموظفين، وبوابة الإدارة.
- الأمان والتدقيق: سجل تدقيق شامل (Audit Log)، مصادقة ثنائية (MFA)، وتشفير JWT.
- التقارير: تقارير طلبات ومدفوعات واستنشاقات + تصدير CSV/Excel/PDF.

=== البنية التقنية (التكنولوجيا) ===
- الفرونت إند: Next.js 16.3.5, React 19.2.8, Tailwind CSS
- الباك إند: API Route 112, Business Logic
- قواعد البيانات: PostgreSQL + Prisma, Neon Cloud
- الأمان والاستضافة: Redis (Upstash), JWT, MFA, Vercel
